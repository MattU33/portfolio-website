# Personal Portfolio Web Application

A responsive, multi-page static portfolio web application built to showcase IT Support capabilities, JavaScript programming projects, and system administration expertise.

## Project Overview

This application serves as a professional portfolio built with standard-compliant HTML5, modular CSS, and client-side JavaScript. It features a responsive layout, WCAG 2.1 AA accessibility considerations, dynamic project filtering, and interactive form handling.

## Features

- **Multi-Page Static Architecture:** Separate semantic pages for Home, Projects, Skills, and Contact.
- **Client-Side Search & Filter:** Dynamic JavaScript search bar on `projects.html` allowing real-time keyword filtering.
- **Form Handling:** Interactive validation and feedback handling on `contact.html`.
- **Responsive Layout:** CSS Flexbox and Grid layouts built for mobile, tablet, and desktop viewports.
- **Accessibility:** High-contrast color palette, semantic structural elements, and clear focus states.
